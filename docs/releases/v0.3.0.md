# Robinne v0.3.0 (Pre-release)

这是一次阶段性基线预发布版本，整合了自 `v0.2.2` 以来完成的 AI 分析工作台、时间线（事务线）体系、数据实时刷新、任务生命周期完善与界面视觉打磨，并统一了基于 `dev` 主干的开发与 Pre-release 发布流程。

## 本次更新

- **AI 分析工作台**：新增 AI 面板，支持按时间范围、标签、人物与关键词生成“过去总结”和“未来提炼”；支持 OpenAI 兼容与 Anthropic 协议、设置页测试连接、API Key 本地配置优先、Token 消耗统计，并修复 Kimi 兼容请求参数问题。
- **时间线与事务线**：新增 `lines` 数据模型（SQLite schema v8），支持 `~时间线` 与 `~项目/时间线`（含全角 `～`）语法解析、联想与归属管理；默认合并时间线改用虚拟列表优化性能，并重做按事务拆分的共享日期段并行时间线视图（含当前与起点标记）。
- **数据实时刷新**：新增 `StoreEvent` 数据变更广播，看板、任务、记录、时间线和搜索面板自动订阅刷新，标题栏新增手动刷新按钮。
- **任务生命周期与提醒修复**：补全任务重新打开（Reopen）流程、完善已完成任务列表入口与交互，修复提醒线程并发写回竞争以及修改提醒时间后 `notified_at` 未重置的问题。
- **视觉打磨**：优化任务面板与侧边栏的 Claude 风格视觉层级与排版。
- **开发与发布流程**：引入 macOS / Windows 双平台常规 CI，`0.x` 版本直接作为 GitHub Pre-release 发布。

## 验证重点

- 下载 `Robinne-v0.3.0-macos.zip` 并解压，将 `Robinne.app` 拖入 `/Applications` 后正常启动。
- 在快速输入与主面板中使用 `~项目/时间线` 归类任务与记录，确认时间线的合并视图、拆分并行视图及多面板实时刷新正常。
- 如使用 AI 总结，先在设置页执行“测试连接”，确认配置可用后再进入 AI 面板生成总结。

## 已知说明

- 当前 macOS / Windows 产物仍未接入正式签名与公证，macOS 安装请优先使用 ZIP 中的 `Robinne.app`（`.dmg` 仅用于验证构建链路）；后续将接入个人 Developer ID 签名与公证流程。
